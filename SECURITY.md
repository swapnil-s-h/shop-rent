# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please do not report it through
a public GitHub issue.

Use GitHub's private vulnerability reporting feature, if enabled, or contact
the repository maintainers privately.

Please include:

- A description of the vulnerability.
- Steps to reproduce it.
- Potential impact.
- Any suggested mitigation, if available.

## Supported Versions

Security fixes will be provided for the latest actively maintained version.
